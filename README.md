# 🎓 大学講義 音声ノートAI

> 講義の録音ファイルをアップロードするだけで、**文字起こし・3行要約・重要ポイント**を自動生成するWebアプリです。  
> Google の最新AI「Gemini 2.5 Flash」を使用。インストール不要、ブラウザだけで動作します。

---

## 📸 こんなことができます

| できること | 説明 |
|-----------|------|
| 📝 **文字起こし** | 講義音声をそのままテキストに変換 |
| 💡 **3行要約** | 講義の核心を3文でまとめる |
| 📌 **重要ポイント** | 試験に出そうな要点を箇条書きで抽出 |
| 📋 **ワンクリックコピー** | 結果をすぐにノートアプリやSlackに貼り付け |

---

## ✅ 使う前の準備（一度だけ）

### 必要なもの

- **パソコンまたはスマートフォン**（Chrome / Safari / Firefox / Edge の最新版）
- **Googleアカウント**（無料）
- **Gemini APIキー**（以下の手順で取得、無料枠あり）

### APIキーの取得手順

APIキーとは、アプリがAIに問い合わせるための「合言葉」です。無料で取得できます。

**1.** ブラウザで以下のURLを開く  
→ https://aistudio.google.com/apikey

**2.** Googleアカウントでログインする（まだしていない場合）

**3.** 「**Get API key**」ボタン → 「**Create API key**」をクリック

**4.** 画面に表示された文字列（`AIza` から始まる長い文字列）をコピーする

**5.** コピーしたキーをメモ帳などに一時保存しておく  
　（このキーは他人に見せないでください）

> ⚠️ **無料枠について**  
> Gemini APIは一定回数まで無料で使用できます。講義数本程度であれば料金は発生しません。  
> 詳細は → https://ai.google.dev/gemini-api/docs/pricing

## 🚀 アプリの使い方

### 画面の説明

```
┌─────────────────────────────────────┐
│  🎓 音声ノートAI    [Gemini 2.5 ●] │ ← ヘッダー
├─────────────────────────────────────┤
│  ⚙️ APIキー設定  [未設定] ∨         │ ← 最初はここから
├─────────────────────────────────────┤
│  講義名: [___________________]      │
│  ┌─────────────────────────────┐   │
│  │  🎵 音声ファイルをドロップ  │   │ ← 録音ファイルを入れる
│  └─────────────────────────────┘   │
│  [▶ 解析を開始する]                 │ ← このボタンを押す
├─────────────────────────────────────┤
│  📝 文字起こし                       │
│  💡 3行要約                          │ ← 結果がここに表示される
│  📌 重要ポイント                     │
└─────────────────────────────────────┘
```

### ステップ1 — APIキーを設定する

1. 「⚙️ APIキー設定」の行をクリックしてパネルを開く
2. 取得したAPIキー（`AIza...`）を入力欄に貼り付ける
3. 「**保存**」ボタンをクリック
4. 「設定済み」と表示されれば成功 ✅

> 💡 一度保存すると、次回以降は入力不要です（ブラウザに記憶されます）

### ステップ2 — 講義名を入力する（任意）

テキスト欄に講義名を入力します（例: `情報科学入門 第7回`）  
入力しなくても解析は動きます。入力すると要約の精度が上がります。

### ステップ3 — 音声ファイルをアップロードする

以下のいずれかの方法でファイルを選びます。

**方法A：ドラッグ＆ドロップ**  
エクスプローラー（またはFinder）からファイルをつかんで、点線の枠の中に落とす

**方法B：クリックして選択**  
点線の枠をクリック → ファイル選択ダイアログが開く → ファイルを選ぶ

**対応している音声ファイルの種類**

| 形式 | 拡張子 | 代表的な録音アプリ |
|------|-------|-----------------|
| MP3 | `.mp3` | 多くのICレコーダー |
| WAV | `.wav` | Windows ボイスレコーダー |
| AAC | `.aac` `.m4a` | iPhoneのボイスメモ |
| FLAC | `.flac` | 高音質録音アプリ |
| OGG | `.ogg` | Androidの録音アプリなど |
| AIFF | `.aif` `.aiff` | Mac系アプリ |

> ⚠️ **ファイルサイズの上限: 18 MB**  
> おおむね10〜15分の講義音声が目安です。それより長い場合はファイルを分割してください。

### ステップ4 — 解析を開始する

「**▶ 解析を開始する**」ボタンをクリックします。

処理中は3つのステップが順番に表示されます：

```
● 音声データを読み込み中…
● 文字起こし中…
● 要約・要点を生成中…
```

> ⏱️ 処理時間の目安：音声1分あたり約5〜15秒かかります。  
> 長い講義では数分かかることもあります。そのままお待ちください。

### ステップ5 — 結果を確認・コピーする

解析が完了すると3つのセクションに結果が表示されます。

- 右上の「**コピー**」ボタン：そのセクションだけをコピー
- 画面下の「**すべてコピー**」ボタン：3セクション分をMarkdown形式でまとめてコピー
- 「**最初から**」ボタン：画面をリセットして別の音声を解析

## 🔒 プライバシーとセキュリティ

| 項目 | 内容 |
|------|------|
| APIキーの保存場所 | お使いのブラウザ内のみ（サーバーには送られません） |
| 音声データの扱い | Google Gemini APIに送信・解析後は保存されません |
| 第三者へのデータ共有 | このアプリ自体はデータを収集・保存しません |

> ⚠️ **共有のパソコンを使う場合**  
> 使用後は「**削除**」ボタンでAPIキーを消去してください。  
> 他の人にAPIキーが見られるリスクを防げます。

## 🐛 うまくいかないときは

### よくあるエラーと対処法

| エラーメッセージ | 原因 | 対処法 |
|----------------|------|--------|
| 「APIキーが無効または権限がありません」 | APIキーが間違っている | キーを削除して再入力。`AIza`で始まるか確認 |
| 「リクエストが多すぎます」 | 短時間に解析しすぎた | 1〜2分待ってから再試行 |
| 「ファイルが大きすぎます」 | 18MB超のファイル | 録音ソフトで音声を分割する |
| 「非対応の音声形式です」 | 対応外のファイル形式 | MP3またはWAVに変換して再試行 |
| 「ネットワークに接続できません」 | インターネット接続が切れた | 接続を確認して再試行 |
| 解析ボタンが押せない | APIキー未設定 or ファイル未選択 | 両方を確認する |

### ファイルをMP3に変換する方法（無料）

**Windows の場合**
1. [Audacity](https://www.audacityteam.org/)（無料ソフト）をインストール
2. ファイルを開く → 「ファイル」→「書き出し」→「MP3として書き出し」

**Mac の場合**
1. QuickTime Player でファイルを開く
2. 「ファイル」→「書き出す」→「オーディオのみ」（m4a形式で保存、そのまま使用可）

**オンライン変換（インストール不要）**
→ [CloudConvert](https://cloudconvert.com/) で変換できます

## 🌐 GitHub Pages への公開手順

このアプリをインターネット上で誰でもアクセスできる状態にします。  
**GitHubアカウント**が必要です（無料）。

### 事前準備

1. GitHubアカウントを作成する（まだの場合）  
   → https://github.com/join

### 手順（ステップバイステップ）

#### A. リポジトリを作成する

**1.** GitHub にログインし、右上の「+」→「**New repository**」をクリック

**2.** 以下のように設定する：
```
Repository name: lecture-notes-ai   ← 好きな名前でOK
Description:     大学講義 音声ノートAI（任意）
Public / Private: Public ← 必ずPublicを選ぶ
```

**3.** 「**Create repository**」をクリック

#### B. ファイルをアップロードする

**4.** 作成したリポジトリのページで「**Add file**」→「**Upload files**」をクリック

**5.** 以下の6ファイルをすべてアップロードする（ドラッグ＆ドロップ可）：
```
index.html   ← メインHTML
style.css    ← スタイル
app.js       ← アプリロジック
gemini.js    ← APIモジュール
README.md    ← 本ファイル（あると親切）
```

**6.** 画面下の「**Commit changes**」ボタンをクリック

#### C. GitHub Pages を有効にする

**7.** リポジトリ上部の「**Settings**」タブをクリック

**8.** 左サイドバーの「**Pages**」をクリック

**9.** 「**Source**」の欄を以下のように設定する：
```
Source: Deploy from a branch
Branch: main    ← または master
Folder: / (root)
```

**10.** 「**Save**」ボタンをクリック

#### D. 公開URLを確認する

**11.** 数分待った後、「Pages」ページを再度開く

**12.** 以下のようなURLが表示される：
```
https://あなたのユーザー名.github.io/lecture-notes-ai/
```

**13.** このURLをブラウザで開いてアプリが表示されれば公開完了 🎉

> ⏱️ 公開までに最大5〜10分かかることがあります。  
> URLが表示されない場合はページを更新してみてください。

### ファイルを更新したいときは

1. GitHubのリポジトリページで更新したいファイルをクリック
2. 右上の鉛筆マーク（✏️）をクリックして編集
3. 「**Commit changes**」で保存
4. 数分後に自動で公開URLに反映されます

## 🛠️ ローカルで動かす方法（開発者向け）

このアプリはES Modulesを使用しているため、ファイルをダブルクリックしても動きません。  
以下のいずれかでローカルサーバーを立ち上げてください。

```bash
# Node.js がある場合（おすすめ）
npx http-server . -o -p 8080

# Python 3 がある場合
python -m http.server 8080
```

ブラウザで `http://localhost:8080` を開く
